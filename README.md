# MLOps Bootcamp Repository

This repository is part of the **MLOps Bootcamp** and contains hands-on projects, exercises, and implementations related to Machine Learning Operations (MLOps) practices.

## Overview

This repository demonstrates practical MLOps concepts including:
- ML model development and experimentation
- Model tracking and versioning with MLflow
- Workflow orchestration
- Best practices for ML in production

## Repository Structure

- **01-intro/** - Introduction to MLOps concepts and initial model development
  - Duration prediction notebook and experiments
  - MLflow integration for experiment tracking

- **03-orchestration/** - Workflow orchestration implementations
  - Python scripts for orchestrated ML pipelines
  - Model training and deployment workflows

## Technologies Used

- **MLflow** - Experiment tracking and model registry
- **Python** - Primary programming language
- **Jupyter Notebooks** - Interactive development and experimentation

## About

This repository serves as a practical learning resource for the MLOps bootcamp, providing real-world examples of implementing MLOps practices and tools.
